# 対戦！迫撃砲ゲーム (Mortar Artillery Game)

HTML5 Canvas と TypeScript / JavaScript で開発した、2人プレイ感覚で遊べるターン制の砲撃シューティングゲームです。プレイヤーと敵が交互に弾を撃ち合い、相手の撃破を目指します。

## 🎮 デモ・特徴
- **破壊可能な地形**: 砲弾が着弾すると、その場所の地面が丸く削り取られます。地形の形が変わることで、射線の管理が重要になります。
- **動的な風向き変化**: ターンごとに風向きと風速（画面中央に表示）が変化します。風の抵抗を計算に入れた角度・威力の調整が必要です。
- **インテリジェントな敵AI**: プレイヤーとの距離と現在の風況を計算し、自動で最適なパラメータを予測して狙い撃ってきます。

## 🕹️ 操作方法
ゲーム画面（Canvas）を一度クリックしてアクティブにしてから操作してください。

| キー | 操作内容 |
| :--- | :--- |
| **矢印キー 上 (↑)** | 砲台の角度を上げる（最大 90°） |
| **矢印キー 下 (↓)** | 砲台の角度を下げる（最小 0°） |
| **矢印キー 右 (→)** | 砲弾の発射威力を上げる（最大 20） |
| **矢印キー 左 (←)** | 砲弾の発射威力を下げる（最小 1） |
| **スペースキー (Space)** | 砲弾を発射！ |

※ キーボードが「全角入力（日本語入力）」モードになっているとスペースキーが反応しないため、必ず**「半角英数」モード**で操作してください。

## 🛠️ 技術的なこだわり・バグ修正の軌跡
開発の過程で、ブラウザの仕様や衝突判定に起因するいくつかの技術的課題をクリアしています。

1. **`willReadFrequently: true` による描画の超高速化**
   毎フレームごとに `getImageData` を用いてミリ秒単位の地形衝突判定（ピクセルレベルの当たり判定）を行っています。一部のブラウザで発生する描画の目詰まり・フリーズの警告を回避するため、Canvasコンテキストに `willReadFrequently: true` オプションを明示的に指定し、プロセッサによる高速読み戻しを最適化しました。
2. **発射時の自爆判定ガード（マズルオフセット）**
   弾が発射された瞬間に自分の足元の地形（グラウンド）に衝突して爆発してしまうバグを解決するため、プレイヤーおよび敵の機体サイズを考慮し、弾の生成初期座標を上部（`y - 25`）へオフセットする物理調整を施しています。
3. **ブラウザ標準スクロールの防止**
   矢印キーやスペースキーを押した際に、ブラウザ画面が勝手に上下スクロールして操作がブレるのを防ぐため、`e.preventDefault()` を実装してゲーム操作キーを最優先でモックしています。
